Matomo is a MediaWiki extension that adds privacy-friendly Matomo pageview
tracking. It tracks only which pages are viewed, how often, and in what
sequence — no personally identifiable information is collected.

== Documentation

For Matomo itself see https://matomo.org[matomo.org].

== Testing

Local testing and CI are supported by Docker and Make:

[source,console]
----
make ci
----
